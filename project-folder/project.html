Here are some examples of projects that demonstrate my experience with programming, problem-solving, database management, and software development.

Car Instrument Simulator

A Java simulation that demonstrates concurrent vehicle fueling while tracking the vehicle's fuel gauge and odometer until the available fuel is depleted.

Parking Ticket Simulator

A Java program using aggregate classes to simulate an officer inspecting a parked vehicle, checking its parking meter, and determining whether a parking ticket should be issued based on established conditions.

Lo Shu Magic Square

A 3x3 grid containing the numbers 1 through 9, arranged so that every row, column, and diagonal produces the same sum.

Magic 8 Ball

An interactive program that generates randomized responses to user input, simulating the responses of a traditional Magic 8 Ball.

Hotel Management System

A database-driven application that organizes and updates hotel customer information, including reservations and essential guest details, while managing benefits associated with different customer tiers and suites.
